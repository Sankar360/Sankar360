## 🚀 Featured Project — Bssshop

### 🛒 Full-Stack E-Commerce Web Application

`Laravel` `React` `PHP` `PostgreSQL` `Redis` `Docker` `Razorpay` `REST API` `Sanctum` `GitHub` `GitHub Actions` `CI/CD` `Render`

**🌐 Live Demo:**
https://bssshop-react.onrender.com/

Bssshop is a full-stack e-commerce application that I developed and progressively modernized from a traditional PHP/CodeIgniter application into a **Laravel + React architecture**.

The current version demonstrates practical experience with **REST API development, authentication, PostgreSQL, Redis, Docker containerization, Razorpay payment integration, GitHub version control, CI/CD, and cloud deployment on Render.**

### ✨ Key Features

* 🛍️ Product catalog, categories & product variants
* 📦 Product stock management
* 🔍 Product search, filtering & product details
* 🛒 Shopping cart & wishlist
* 🔐 Authentication using Laravel Sanctum
* 👤 Customer profile management
* 📝 Blog, FAQ & contact modules
* 🛠️ Admin functionality
* 💳 Razorpay payment integration
* 🧾 Order & checkout workflow
* 🔄 RESTful API communication between React and Laravel
* ⚡ Redis integration
* 🐘 PostgreSQL database
* 🐳 Dockerized Laravel application
* 🚀 Deployment on Render
* 🔁 GitHub-based CI/CD workflow
